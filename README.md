# Прототипы сайтов (GitHub Pages)

Каждый клиент — отдельная папка латиницей с файлом index.html:
- demo-salon/ → https://ЛОГИН.github.io/proto/demo-salon/

Новая версия прототипа = заменить index.html в папке клиента (история версий хранится в GitHub автоматически).
Прототипы закрыты от поисковиков (meta noindex в каждой странице), но репозиторий публичный: любой, у кого есть ссылка, может открыть страницу.
